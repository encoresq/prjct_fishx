# FishSpot

Десктопное приложение для ведения дневника рыбалки. Позволяет записывать уловы, просматривать статистику, выбирать локации на карте и соревноваться с другими пользователями.

## Функционал

*   Авторизация и регистрация пользователей (пароли хешируются через bcrypt).
*   Личный профиль со статистикой (количество рыбы, максимальный вес, аватар).
*   Добавление записей об уловах (вид рыбы, вес, локация, приманка).
*   Интерактивная карта на базе Yandex Maps API для отображения локаций.
*   Таблицы лидеров: рейтинг рыбаков по общему весу и список лучших трофеев.
*   Выбор лучшего улова в профиль через Drag-and-Drop.
*   Смена цветовых тем интерфейса (Светлая, Темная, Ocean) с сохранением выбора.

## Стек

*   **Язык:** Python 3
*   **GUI:** PyQt6 (включая QWebEngineView для карт)
*   **БД:** SQLite
